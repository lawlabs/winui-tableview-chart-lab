# WinUI TableView & Chart Lab

Лаборатория с английским и русским интерфейсом **нативных TableView и Chart**, опубликованных в Windows App SDK **2.5.4-experimental** 29 сентября 2026 года. Компоненты берутся из SDK, без сторонних замен.

По умолчанию приложение запускается на английском. Переключатель English / Русский сохраняет выбор. При смене языка данные лабораторий создаются заново, тема и раздел сохраняются.

[English README](README.md). Лицензия: [MIT](LICENSE).

## Запуск

Требуются Windows, .NET SDK 10 и настроенная среда WinUI 3. Здесь проект собран и проверяется как **packaged x64**. SDK доставляется вместе с приложением (`WindowsAppSDKSelfContained=true`), включая ресурсы новых компонентов. NuGet-пакет WinApp CLI 0.7.1 входит в зависимости проекта.

Из этой папки:

```powershell
.\BuildAndRun.ps1
```

С диагностикой запуска:

```powershell
.\BuildAndRun.ps1 -Diagnostics
```

Скрипт восстанавливает зависимости, закрывает предыдущий экземпляр именно этого приложения, собирает и запускает новое окно. Можно также открыть `SdkComponentLab.slnx` в Visual Studio. Предупреждения `WMC1501` о preview-компонентах ожидаемы.

## Что пробовать

| Раздел | Возможности |
| --- | --- |
| TableView | 6 сценариев: смешанные столбцы, Auto, Star, интерактивные шаблоны, 10 000 строк, пустые данные |
| Преобразования таблицы | Filter / ClearFilter, GroupBy по свойству и вычисляемому ключу, reference key с identity selector, заголовки групп и сворачивание, сортировка по столбцу/пути/делегату, несколько ключей в Source, custom comparer и отмена Sorting |
| Столбцы | Текст, шаблоны, custom column, width/min/max, visibility, Leading frozen, изменение порядка через Columns, добавление/удаление, шаблоны заголовков и selectors, подсказки |
| Редактирование | F2 / двойной щелчок, Enter / Esc, CommitEdit / CancelEdit, запрет начала/сохранения, INotifyDataErrorInfo для Score, отдельный CellEditingTemplate |
| Оформление таблицы | Плотность, линии, полосы, заголовки, IsReadOnly, направление RTL, выделение Single/None |
| Chart | 10 сценариев: Line / Area / Bar, смешанные серии, числовые категории X, даты, две Y, горизонтальные столбцы, пустые данные, 200 точек |
| График | Добавление/удаление серий и точек, изменяемые Samples, поток, редактор значений, видимость, легенда, названия и кисти |
| Серии | Stroke / Fill, толщины и стили штрихов, подписи/маркеры и их кисти, все MarkerShape, overrides отдельных точек, выбор оси Y |
| Оси | Linear / Category / DateTime, диапазоны, интервалы, сортировка категорий, формат дат, метки, подписи, линии и сетка |
| Инспектор API | Публичные свойства реальных объектов лабораторий, изменение простых значений, восстановление, поиск, базовые свойства WinUI, полный каталог типов/методов/событий в буфер обмена |
| Тема | Системная / светлая / тёмная. Новый SetThemeResourceBinding также используется в коде лаборатории |

Настройки справа прокручиваются. В небольшом окне меню сворачивается, настройки располагаются под компонентом и доступны через прокрутку рабочей области; журнал таблицы автоматически закрывается. Дополнительные команды доступны в меню `…`. Кнопки «Проверить API» выполняют проверки конфигураций и операций; визуальная отрисовка проверяется отдельно.

При изменении данных Chart приложение заново назначает `Samples.ItemsSource` типизированные массивы: `string[]`, `double[]` или `DateTimeOffset[]`. Редактор и поток управляют исходными данными приложения; автоматическое наблюдение native Chart за `ObservableCollection<object>` здесь не предполагается.

Инспектор изменяет поддерживаемые простые свойства через setter. Методы и события отображаются как справочник; соответствующие операции выполняются командами лабораторий. Ввод ключа ресурса для Brush присваивает объект кисти, а динамическая привязка темы через новый `SetThemeResourceBinding` демонстрируется отдельно.

**Границы релиза:** TableView пока поддерживает одиночное выделение и Leading frozen. Сам заголовок сортирует по одному столбцу; несколько ключей можно задать через TableViewSource. Перестановку столбцов осуществляет приложение, встроенного drag reorder нет. Chart публикует декартовы Line/Area/Bar; pie/3D и встроенные zoom/pan не объявлены. Инспектор показывает и зарезервированные enum значения, поэтому эксперимент с ними не доказывает поддержку функции.

При запуске `LineSeries.XAxis = new LinearAxis()` пакет отклоняет назначение с `0x80070057`: несовместимый масштаб оси и слота данных. Проверено с заполненными `double[]`, до и после привязки источников. Кнопка «Проверить LinearAxis на X» позволяет повторить эксперимент, сохраняя текущий график. Числа в рабочих сценариях X передаются как строковые категории; расстояния между ними одинаковы. Настоящая `LinearAxis` используется на Y. Демонстрационные даты заданы в UTC; редактор принимает ISO-даты и явное смещение времени.
