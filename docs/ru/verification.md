# Проверка WinUI TableView & Chart Lab

Проверено 7 октября 2026: Windows App SDK 2.5.4-experimental, .NET SDK 10.0.401, packaged x64 Debug, WinApp CLI 0.7.1.

Успешно выполнены **79 UI/API-проверок**: TableView — 25, Chart — 29, оформление — 7, оболочка/инспектор — 7, компактное окно — 5, языки — 6. Ошибок сборки нет; четыре WMC1501 предупреждают об экспериментальном API.

[Полный отчёт на английском с JSON результатами](../verification.md). [Галерея английских скриншотов](../../README.md#screenshots). [Каталог 55 публичных типов](../public-api.txt).

Первый запуск использует английский язык. Проверены переключение на русский и обратно, сохранение текущего раздела и темы. Выбор языка сохраняется; при переключении лаборатории пересоздают демонстрационные данные.

Основные наборы тестов проверяют русские сообщения; общий скрипт включает русский перед их запуском и возвращает английский после завершения. Отдельный набор проверяет оба языка. Наборы запускаются последовательно в уже открытом приложении:

```powershell
.\tests\repository-checks.ps1
.\tests\run-ui-tests.ps1 -AppPid <PID>
```

Наблюдения SDK: LinearAxis на X отклоняется; числовые X представлены равномерными категориями. Samples обновляются типизированными массивами. Прозрачность заливки нормализуется в Color.A. Тематические кисти обновляются после разрешения ресурсов. Пустые ключи групп нормализуются. Полный обход UIA TableView иногда встречает устаревшие peers, а peer Chart сообщает нулевую геометрию при видимом графике: отрисовка проверяется по PNG.

High Contrast, screen readers, ARM64/x86, Release trimming и чистая машина не проверялись. Сценарий 10 000 строк проверяет работоспособность без замеров FPS/памяти. Проверки не доказывают каждую комбинацию всех свойств.
